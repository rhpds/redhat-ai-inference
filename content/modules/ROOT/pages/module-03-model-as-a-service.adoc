= Module 3: Expose the Model as a Model-as-a-Service
:navtitle: 3. Model-as-a-Service

== Overview

A deployed model that only one team can reach isn't enough for production
use. This module walks you through configuring the deployed model as a
Model-as-a-Service (MaaS), making it available for shared, scalable
consumption across teams and applications. You configure access controls,
API endpoints, and scaling policies to prepare the model for broader use.

.Prerequisites
Module 1 completed (model deployed); Module 2 completed (model evaluated).

.Duration
20 minutes

== Learning Objectives

* Configure a deployed model as a Model-as-a-Service for shared, scalable consumption
* Manage access controls and API endpoint configuration for the model service
