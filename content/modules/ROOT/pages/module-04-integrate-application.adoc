= Module 4: Integrate the Model into an Application
:navtitle: 4. Integrate into an Application

== Overview

With the model exposed as a service, you now connect it to a consuming
application. This module demonstrates how to integrate the
Model-as-a-Service endpoint into an application using standard API
patterns. You configure the application to call the model service, deploy
it, and observe inference responses flowing through the integration.

.Prerequisites
Module 3 completed — model exposed as a MaaS with a reachable API endpoint.

.Duration
20 minutes

== Learning Objectives

* Integrate a model service into an application using standard API patterns
* Configure application-side settings to consume the Model-as-a-Service endpoint
