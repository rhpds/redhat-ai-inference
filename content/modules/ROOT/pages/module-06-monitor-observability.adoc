= Module 6: Monitor Model Performance through Observability
:navtitle: 6. Monitor Performance

== Overview

A production AI service requires ongoing visibility into how the model
performs under real usage. This module introduces the observability
dashboard in Red Hat AI Enterprise and shows you how to monitor model
serving metrics. You explore dashboards, observe key metrics under load,
and analyze how serving behavior changes as the application sends requests
to the model service.

.Prerequisites
Module 5 completed — end-to-end workflow validated; application actively
sending requests to the model service.

.Duration
20 minutes

== Learning Objectives

* Monitor model serving metrics through the observability dashboard
* Analyze serving behavior under load to identify performance trends

== 6.1 — Explore the Observability Dashboard

. Navigate to the observability dashboard in Red Hat AI Enterprise.
. Locate the model serving metrics panel for the deployed model.
. Review the available metrics:
** Request rate
** Latency (p50, p95, p99)
** Throughput
** Error rate
** Resource utilization (CPU, memory, GPU)

== 6.4 — Analyze Performance Trends

. Examine the relationship between request rate, latency, and resource utilization.
. Identify any performance thresholds where serving behavior changes noticeably.

== Key Takeaways

* The observability dashboard provides real-time visibility into model serving behavior — latency, throughput, error rate, and resource utilization.
* Monitoring under load reveals how the model service responds to increased demand and where performance thresholds exist.
* Serving metrics inform operational decisions: scaling policies, capacity planning, and alerting thresholds.
