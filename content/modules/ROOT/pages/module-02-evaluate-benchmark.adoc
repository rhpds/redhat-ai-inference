= Module 2: Evaluate and Benchmark Model Performance with EvalHub
:navtitle: 2. Evaluate with EvalHub

== Overview

With a model deployed, you need to measure how well it performs before
exposing it to consumers. This module introduces EvalHub — a feature of
Red Hat AI Enterprise for running evaluations against deployed models.
You run benchmark evaluations, analyze the results, and configure a
repeatable evaluation workflow to track performance over time.

.Prerequisites
Module 1 completed — model deployed and serving inference requests.

.Duration
20 minutes

== Learning Objectives

* Analyze model inference performance using EvalHub for evaluations
* Configure a repeatable evaluation workflow for tracking model performance over time
