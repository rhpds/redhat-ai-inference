= Module 5: Validate the End-to-End Workflow
:navtitle: 5. Validate End-to-End

== Overview

The model is deployed, evaluated, exposed as a service, and connected to
an application. This module brings those pieces together by validating the
end-to-end request flow. You trace a request from the application through
the MaaS endpoint to the model and back, troubleshoot a simulated failure,
and confirm that every component in the serving chain is working correctly.

.Prerequisites
Module 4 completed — application deployed and connected to the model service.

.Duration
20 minutes

== Learning Objectives

* Verify end-to-end request flow from application request to model response
* Troubleshoot common issues in the serving chain between the application and the model
